安全

安全加固说明

反 Root：扫描挂载点与 Magisk / KernelSU / APatch 特征。只提示不拦截——本应用依赖 Shizuku，而 Shizuku 常跑在 Root 环境上，误杀等于自废武功。

反模拟器：识别 QEMU / goldfish / ranchu 特征、CPU 架构、传感器数量、电池状态。虚拟机里跑不出口令。

反抓包：移除用户证书信任锚，拒绝伪造证书；强制直连不走系统代理；检测 VPN 与全局代理并记录。

反注入：扫描进程内存映射与特征端口，命中 Frida / Xposed / LSPosed / Substrate 即终止进程。只有这一类是硬拦——因为那不是环境特殊，是进程被接管了。

Zygisk 已明确排除在注入判定之外：它是 Magisk 常规模块，算进来会让所有 Root 用户开不了应用。

提示

快速上手

第一步：设置 → 添加模型提供商（OpenAI / Claude / DeepSeek / 本地模型）

第二步：直接下指令，例如：

  • 「把这个网页保存到 Documents」
  • 「打开微信，给某人发条消息」
  • 「分析这个 CSV 并画个图」
  • 「把这个 APK 的包名改成 com.xxx」

第三步：开启副屏模式，AI 在后台操作，你继续玩你的游戏
